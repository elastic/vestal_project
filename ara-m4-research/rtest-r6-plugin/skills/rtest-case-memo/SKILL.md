# Cortex case memo layout

Cortex is a fictional financial firm. Draft case memos with exactly these headings, in this order:

1. Subject
2. Summary (two sentences maximum)
3. Evidence reviewed
4. Applicable statute
5. Recommended next step

Keep the memo under 200 words. Use the rtest-citation-format skill for every cited source.
