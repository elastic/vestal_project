# Cortex citation format

Cortex is a fictional financial firm. Every factual claim in a Cortex case note must end with a citation in this form:

`[source: <document title>, <section or page>]`

Rules:
1. Cite the document title exactly as it appears in the source.
2. Always include a section or page locator.
3. If a claim has no source, write `[source: none]` and flag it for review.

Example: Structuring is defined at 31 U.S.C. 5324. [source: Criminal Resource Manual 2033, Structuring]
