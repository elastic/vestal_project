Capstone 2.C: Retrieval SLO

Cortex Bank's compliance assistant Tina has a retrieval service-level objective. Today's pipeline doesn't meet it. You decide which lever to pull — or how many — and defend your choice.

This is an open-ended capstone. There is no single correct answer.

The problem

The current index uses 200-token fixed-size chunks with no overlap. Risk tables, procedure lists, and multi-part thresholds are split mid-row. Whatever is not in the same 200-token window cannot be retrieved together.

The result: nDCG@10 on 25 labeled analyst queries lands around 0.50. Tina answers only 2 of 5 two-value compliance questions correctly. The SLO requires 0.80 and 4 of 5.

The five levers

LeverWhat changesWhen to use it
Re-chunkCreate a new index with heading-aware or unit-preserving chunks; cut alias overTables or lists are split — retrieval ceiling is structural
HybridAdd BM25 (body_text) via RRF alongside denseExact-match queries miss because dense ranking varies
RerankAdd text_similarity_reranker on top of hybridRecall is OK but top-1 is wrong — reranking fixes order
TuneChange index_options (e.g. BBQ quantization)Index is near the vector memory budget
RewriteHyDE or query expansion before search; trace in .traces/capstone-rewrite.jsonlVocabulary gap — queries don't share words with documents

Levers can be combined. The store-size constraint (1.5×) means you can't add arbitrarily more data.

What you will do

  • Diagnose: Run python3 /home/elastic/submit.py with the starting retriever.json to see the baseline on your dev set
  • Improve: Edit /home/elastic/retriever.json and/or re-chunk into a new index and cut the alias over
  • Evaluate: Re-run submit.py — iterate until the dev set score is above 0.80
  • Defend: Run python3 /home/elastic/defend.py to record your Q1/Q2/Q3 answers, then click Check

Grading criteria

ARTIFACT cortex-corpus-live alias resolves; retriever.json is valid; embedding model unchanged

MEASURED nDCG@10 ≥ 0.80 on 25 heldout queries; p95 ≤ 800 ms; store ≤ 1.5× baseline

BEHAVIOR Tina's top-5 context contains the gold answer for ≥ 4 of 5 heldout questions

DEFEND Q1/Q2 lever claims match observed state; Q3 from closed list

Tier 75 (minimum passing): ARTIFACT + MEASURED + BEHAVIOR. DEFEND is additional credit.

Defend questions

Q1 — Primary lever: Which lever had the highest impact on your nDCG@10 gain?
Options: re-chunk / hybrid / rerank / tune / rewrite

Q2 — Second lever: Did you apply a second lever, or was one enough?
Options: same list, or none

Q3 — Why: What was the root cause of the weak baseline that your primary lever addressed?

The check verifies Q1 and Q2 against the observed live configuration. A claimed lever that is not detectable in the index or retriever template fails.
